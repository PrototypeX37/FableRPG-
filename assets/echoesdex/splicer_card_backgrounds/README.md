Place Splicer Card background templates in this folder.

Supported formats:
- `.png`
- `.jpg`
- `.jpeg`
- `.webp`

How themes are resolved:
- The theme key is generated from the filename.
- Example: `Temple Dawn.png` -> theme key `temple-dawn`

Usage:
- `$ed splicercard @User temple-dawn`
- `$ed summary temple-dawn` (for yourself)

Notes:
- Keep the same frame style across files.
- Portrait images work best.
