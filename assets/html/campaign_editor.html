Campaign Studio guide

You do not need to know the campaign code. The studio creates the package structure, remembers drafts in this browser, and blocks export when a link or required value is unsafe.

The five-minute workflow

1 · CreateChoose “+ Campaign” for a complete starter flow with an opening, decision, and two endings.
2 · WriteSelect a story beat in the left navigator and replace the instructional starter text with player-facing prose.
3 · ConnectUse “What happens next?” on each non-ending beat. The visual map shows every destination at a glance.
4 · EnrichAdd requirements only when access should be conditional, and consequences exactly where the player causes them.
5 · VerifyRun Check. Every problem has an “Open problem” button that returns to the affected campaign or story beat.
6 · PublishKeep work in Draft, export the checked JSON, import it into the bot, then activate it when ready for players.

Start with the player experience

Create story beats in Flow, connect each beat to what follows, then add requirements only where a path should sometimes be hidden. Put consequences on the exact action that causes them.

Requirement

A rule that decides whether content is available: standing, an earlier choice, relationship affinity, a location state, or any typed story value.

Consequence

A durable change caused by entering a node or choosing a path: standing, membership, affinity, world state, or a permanent reward.

Scenario

A resumable sequence of stages. Every reachable stage must offer a route to an outcome, including failure outcomes.

Warfront

A deterministic multi-front operation. Every possible number of held fronts needs an unconditional result so failure always continues.

Epilogue fragment

A conditional paragraph assembled at the ending and frozen into the player’s permanent ending record.

Campaign systems

Guided companion, camp, location, service, home, and autonomous-event builders shared by the whole campaign.

Safe publishing

Keep campaigns in Draft while writing. Check the package until every error is resolved. Increase Content version when replacing an installed package; players already in progress retain their original snapshot.
